# Air Tractor AT-802 Pilot Dossier (Light Edition) — TC. Luis Anderson Carrero Pérez

Implementación web oficial del proyecto **Air Tractor AT-802 Pilot Dossier** (`projects/13694640903286686461`), sincronizada directamente desde **Google Stitch MCP** en su versión **Light Aeronautical Dossier (`ce3f045c7f4f4cc390c0340d2ccf31bc`)** y publicada en **GitHub** (`https://github.com/visualmenterandom-1/Spitfire.git`).

---

## 🎨 Paleta de Colores & Sistema de Diseño (Light Aeronautical Precision)

* **Fondos & Superficies (`aero-50` / `white`):** `#FFFFFF` (Blanco Puro Técnico) y `#F8FAFC` / `#F1F5F9` con retícula milimétrica de carta aeronáutica (`hud-grid-overlay`).
* **Texto & Estructura (`aero-900` / `aero-600`):** `#0F172A` (Slate 900) para titulares de alta legibilidad y `#475569` para cuerpo técnico.
* **Ámbar Aeronáutico (`aviation-amber`):** `#D97706` / `#F59E0B` para indicadores de mando, turbinas PT-6, bordes de plano técnico (`blueprint-corner`) y llamadas a la acción.
* **Rojo Retardante SEAT (`aviation-crimson`):** `#DC2626` para métricas y caudal de extinción de incendios forestales (338 descargas SEAT).
* **Azul Aviónica HUD (`aviation-hud`):** `#0284C7` para telemetría multimotor, turbina y competencia lingüística.
* **Verde Operacional (`aviation-emerald`):** `#059669` para estados activos, instrucción, certificaciones vigentes y verificación SMS.
